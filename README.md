# Michael Russum — Applied AI & Forward Deployed Engineer Portfolio

Minimalist, engineering-first portfolio showcasing production AI deployments, RAG evaluation benchmarks, and enterprise FDE case studies.

## Local Development

```bash
npm install
npm run dev
```

## Linting & Formatting (Biome)

```bash
npm run lint
npm run format
```

## Deploy to Vercel

1. Push this repository to GitHub (`mrussum/portfolio`).
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Vercel automatically detects Vite (`npm run build` -> `dist`) and deploys.
